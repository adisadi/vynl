# Introduction

Welcome to **`vynl`** — a cross-platform Rust TUI Spotify client with native terminal cover art, built under **GPL-3.0-or-later**.

## Core Philosophy

- **Desktop Feature Parity** in the terminal (integrated `librespot` playback + Spotify Connect remote control).
- **Cross-Compile First**: Pure Rust wherever possible (`rustls`, `redb`, `nucleo`, `zbus`).
- **Strictly Spotify-Only**: Zero telemetry and zero third-party cloud APIs.
- **Crisp Cover Art**: Kitty, iTerm2, Sixel, and 24-bit TrueColor Halfblocks with Modal-Aware Image Occlusion.
