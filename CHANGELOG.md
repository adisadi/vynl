### Added
- Phase 0 Open-Source repository bootstrap: modular Cargo workspace (`vynl-core`, `vynl-spotify`, `vynl-player`, `vynl-images`, `vynl-system`, `vynl-tui`).
- Cross-platform CI/CD pipelines, `cargo-deny`, `cargo-dist`, `release-plz`, OpenSSF Scorecard, Devcontainer, Nix Flake, `AGENTS.md`, ADRs, and mdBook scaffold.
- Pure-Rust domain models, Elm reducer skeleton, WCAG-AA theme contrast engine, Modal-Aware Image Occlusion geometry, and `vynl doctor` diagnostics CLI.
